Memory and JVM

Recommended, and what Aikar's flags assume: a fixed-size heap avoids G1 resizing pauses. Turn it off to let the JVM grow the heap from its own default. The heap size itself is set per server in Manage Server.
Added ahead of whatever is in the flags box, so the two do not need to repeat each other. Aikar's large-heap variant is used automatically above 12 GB.
Adds -XX:+ExitOnOutOfMemoryError. Without it, a server that runs out of heap usually does not die: it keeps running half-broken while the panel still reports it as running. With it, the process exits and restart-on-crash brings it back cleanly.
